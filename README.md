# 🛍️ Pabilli

**Pabilli** is a web-based ordering and business management platform designed to help small businesses digitize their operations. Customers can browse products, place orders, and interact with businesses through an intuitive online interface, while administrators can efficiently manage products, orders, and customer information.

This project was developed in **partial fulfillment of the requirements for ITPROG (Integrative Programming)** at **De La Salle University**.

---

## 📖 Overview

Pabilli aims to simplify the online ordering experience for both customers and business owners. The platform provides a centralized system for managing products, processing customer orders, and maintaining business information through a responsive web application.

Developed in partial fulfillment of the **ITPROG** course requirements, this project demonstrates fundamental software development concepts including CRUD operations, user authentication, database management, and responsive web development.

---

## ✨ Features

### Customer Features

* 👤 User Registration & Login
* 🛒 Browse Available Products
* 🔍 Search and Filter Products
* 📦 Place Orders
* 📜 View Order History
* 👤 Manage User Profile

### Administrator Features

* 📦 Add, Edit, and Delete Products
* 📋 Manage Customer Orders
* 👥 Manage User Accounts
* 📊 Monitor Inventory and Product Listings
